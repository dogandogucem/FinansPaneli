TCMB EVDS 3 Finans Paneli

Gereksinimler: PHP 8.1+, cURL, internet erişimi.

1. index.php dosyasını PHP sunucunuza yerleştirin.
2. Sunucuda TCMB_EVDS_API_KEY ortam değişkenine EVDS API anahtarınızı tanımlayın.
3. Tarayıcıdan index.php sayfasını açın.
4. Grafik için Chart.js CDN bağlantısı gereklidir.

Seri: TP.PBD.H17
Panel, ham seri düzeyindeki 7 gün, 1 ay, 3 ay ve 1 yıl değişimlerini hesaplar.
Serinin metaverisi doğrulanmadan bu değerleri resmi TÜFE enflasyonu olarak etiketlemeyin.
Veri API anahtarı olmadan test edilememiştir.
